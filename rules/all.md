# House rules for every worker

These are the default house rules. Change them to suit how you work: copy a file with
`hw rules copy NAME` (or `--project PROJECT` for one Project) and edit the copy.

- Read the whole brief before acting. The user's original request is the authority; the
  coordinator's notes are a proposal, not a narrower scope.
- Nobody can answer you during the task. If a question can be settled by running something,
  run it. Only a real product or preference choice is a question; report it as the brief says.
- Make the smallest change that fully does the job. Keep the project's existing style.
- Prove behaviour by running it, not by reading the code. Record exact commands and outputs.
- Git: commit locally on your own branch only. Never push, merge, rebase shared branches or
  deploy unless the brief names that exact action.
- Never print secrets, tokens or keys, and never ask anyone to paste them.
- Stop everything you started (servers, browsers, databases) and delete temporary files
  before you finish. Never kill a process you did not start.
